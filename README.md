# 🌍 Global Economic Dashboard | Tableau

## 📌 Project Overview
This project presents an interactive analysis of global economic, demographic, and energy indicators using Tableau.

It aims to transform complex data into clear and interactive visualizations that help users compare countries, explore trends, and discover insights across different areas.

## 📊 Dashboards

### 1. Global Economic Dashboard
- Analyzing the Top 10 countries by GDP.
- Comparing GDP per capita across countries.
- Exploring current account balances.
- Visualizing the geographic distribution of GDP per capita.

### 2. Population Dashboard
- Identifying the most populated countries.
- Comparing total fertility rates.
- Analyzing birth and death rates.
- Comparing life expectancy across countries.

### 3. Energy Infrastructure Dashboard
- Comparing oil production and consumption.
- Exploring the relationship between electricity production and GDP.
- Analyzing natural gas production by country.
- Displaying detailed country-level energy indicators.

## ✨ Key Features
- Interactive dashboards and visualizations.
- Geographic maps for country-level analysis.
- Comparative analysis of global indicators.
- Ranked charts highlighting leading countries.
- Multiple dashboards covering related global topics.

## 🛠️ Tools & Technologies
- Tableau
- Data Visualization
- Exploratory Data Analysis (EDA)

## 🎯 Project Objectives
- Explore global economic performance.
- Understand population and demographic patterns.
- Analyze energy production and consumption.
- Present data in an interactive and accessible format.
- Support data-driven exploration and comparison.
